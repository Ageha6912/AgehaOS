## 0. 前置条件（两台设备通用）

- 真机：iPhone（iOS 16+，有刘海档位优先——safe-area env 才非零）+ Android 手机（Chrome 稳定版）。
- 站点：HTTPS 可达（生产 os.ageha.cn 或本机隧道），`viewport-fit=cover` 在场（index.html——没有它 env 恒 0，全部 safe-area 项会假失败）。
- 账号：每台设备注册一个测试账号；「云同步状态」项需**远程认证构建**且在 Settings→账户 打开「云同步」开关（开关入口仅远程认证模式渲染，本地构建静默——`SyncSection` 的状态盒只在「已登录 + 开关开」呈现，`src/apps/settings/SyncSection.tsx:59`）。
- 每项默认口径：行为与 §35 契约一致才算过；「不符合契约」与「契约本身待改」分开记。

## 1. iOS Safari 清单

### 1.1 safe-area 四边（§35.2）

- [ ] **顶**：Safari 浏览态与 PWA standalone 态，状态栏读数（时钟/电量/网络/用户，`MobileStatusBar` 11px 等宽行）不被刘海/灵动岛裁切，内容经黑色占位带顶开（`black-translucent` 下内容延伸进状态栏底下属预期）。
- [ ] **底**：Home indicator 不遮 Dock——Dock 坐 `max(env(safe-area-inset-bottom), 12px)` 预留带上方，最后一位可完整点按。
- [ ] **左/右（横屏）**：横屏旋转后左右 inset 生效，内容不被传感器缺口压住；转回竖屏恢复。
- [ ] 壁纸全幅铺满不被安全区裁剪（壁纸层挂未加 padding 的 shell 根，§35.2 壁纸例外）。

### 1.2 PWA 安装与 standalone（§35.9 安装条 iOS 指引分支）

- [ ] Home 尾部安装条呈现 **iOS 指引分支**（分享 → 添加到主屏幕两步文案，**无可点安装钮**——iOS 无 web 安装 API，指引即能力全部；出现可点「安装」钮即为缺陷）。
- [ ] 跟随指引真实安装：分享菜单出现「添加到主屏幕」，图标与名称正确。
- [ ] 从主屏图标启动 = standalone（无 Safari 工具栏），`data-shell="mobile"` 正常渲染，状态栏样式 `black-translucent`。
- [ ] 关闭安装条（44×44 关闭钮）后不再打扰（localStorage 版本键 `agehaos.mobile.pwa.installDismissed.v1`）；重装/清 Safari 数据后重现。
- [ ] standalone 内点开应用 → 浏览器/系统返回能回到 Home 且**不退出 PWA**（popstate 契约：返回键落在自己的栈位上）。

### 1.3 手势：上滑 / 长按 / 边缘返回（阈值 §35.9 速查）

- [ ] **边缘返回**：应用视图内自左缘 24px 带内横向滑入，过半（>50% 屏宽）或快甩确认返回 Home；慢速拖一半松手回弹不误触。**叠加观察**：iOS 系统左缘返回手势与 AgehaOS 边缘返回是否抢事件（起点更贴边时系统赢属预期——记下实际分界位置）。
- [ ] **底缘上滑**：Dock 区（含 safe-area 预留带）上滑 15% 屏高或快甩 → 启动器抽屉；Home 内容区纵向滚动不触发抽屉（手势只挂 Dock 区）。
- [ ] **Dock Home 位长按**：按住 ~500ms 驻留 → 最近任务覆盖层；上滑 24px 同效；短按仍是回 Home 不误开。
- [ ] **最近任务卡片上滑**：卡片上滑 >64px 或快甩关闭单应用；点卡片切回已开应用不重启（窗口常驻）。
- [ ] **Files 长按**：文件行长按 500ms 弹操作单，**不弹 iOS 文本选择 callout**（`select-none` 生效）；阈值内抬起仍是正常点击（首击选中再击打开不被破坏）。
- [ ] 手势全程跟手无迟滞（跟手段零 React render，rAF 直写 transform）。

### 1.4 软键盘与 Terminal 快捷键行（M3-5 避让 + M4-4 快捷键行）

- [ ] Terminal 聚焦输入行：软键盘弹起后**输入行保持可视**（根让高、井自动滚到底）；键盘收起恢复。
- [ ] **快捷键行**贴键盘上沿、在输入行之下不遮挡（根最后一个流内子元素）；五键 Esc/Tab/Ctrl+C/↑/↓ 命中 ≥44px。
- [ ] 快捷键真实生效：↑↓ 召回历史、Tab 补全命令名、Esc 清草稿、Ctrl+C 提示符处回显 `^C` 清行；命令执行中（busy）五键随输入行一并禁用。
- [ ] 聚焦输入行**不触发页面自动缩放**（输入 ≥16px 档）；软键盘弹起时抽屉/应用布局不出现整页位移残影。
- [ ] iOS 键盘工具条（预测条）遮挡评估：快捷键行与系统工具条是否重叠、输入行是否仍可视（重叠程度记录，严重则提缺陷）。

### 1.5 通知跳转（M4-2）

- [ ] 制造带跳转目标的通知（触发一次应用崩溃 / 羽化应用失败——开发构建可临时注入）：状态栏铃铛徽标 +1。
- [ ] 通知中心该行：行主体为按钮 + 行尾 chevron（CaretRight）指示；点按后 = 该行转已读 + 直达目标应用（活记录切回/无记录新开）+ 中心关闭。
- [ ] 目标已注销的历史通知（如 L2 今日应用跨日后）行**保持纯展示整条不可点**、无 chevron——不出现点了没反应的死跳。

### 1.6 全局搜索（M4-1）

- [ ] 抽屉搜索框输入：**应用组在前、文件组在后**分组呈现，组标题「应用」「文件」；每组最多 8 条，超限组尾随「共 N 条，仅显示前 8 条」静态文案（不可点）。
- [ ] 文件行显示名称 + 完整路径；点击 → Files 打开并**定位到该文件所在目录**（Files 已开时切回并导航，不重开）。
- [ ] 清空输入回到仅应用列表（无组标题、无文件组）；无命中显示空态文案。
- [ ] 中文/英文输入法下输入防抖无明显迟滞（停顿 200ms 才发起文件搜索）。

### 1.7 云同步状态（M4-3）

- [ ] 已登录 + 开关开：Settings→同步 分区呈现真实状态（「上次同步成功：…」/「正在同步…」/失败行 + 上次成功副行）。
- [ ] 断网（飞行模式）后改动文件 → 状态转失败/离线提示（「设备当前离线……」）；恢复联网后下次变更继续同步。
- [ ] 开关关：呈现「云同步已关闭」+ 指向账户分区的提示行；未登录呈现未登录行——**全程不出现「立即同步」按钮**（无手动触发能力，假按钮即缺陷）。

### 1.8 性能体感（M4-5 探针的真机对照）

- [ ] 首次冷启动（装好后首开）：boot 覆盖层 → Home 全程可感知不白屏（Chromium 门禁阈值 DCL<200ms/FCP<300ms 是桌面级参照，真机 Safari 记录体感秒数即可）。
- [ ] 抽屉/通知中心开合 ~200ms、无掉帧；Home 纵向滚动顺畅。
- [ ] 三支手势连续操作（上滑开抽屉 → 开两个应用 → 长按开最近任务 → 切回 → 左缘返回）无明显发热与卡顿。
- [ ] PWA standalone 冷启动对比浏览器态，体感记录。

## 2. Android Chrome 清单

### 2.1 safe-area 四边（§35.2）

- [ ] **顶**：状态栏读数不被状态栏/挖孔裁切（多数 Android 无刘海档 env=0，占位带落 24px 保底——确认读数行完整可读即可）。
- [ ] **底**：手势条不遮 Dock 最后一位。
- [ ] **左/右（横屏）**：横屏旋转左右 inset 生效、转回恢复。
- [ ] 壁纸全幅铺满不被裁剪。

### 2.2 PWA 安装与 standalone（§35.9 安装条 chromium 分支）

- [ ] 首次到访安装条出现后，**Chrome 自带 mini-infobar 被抑制**（preventDefault 生效，`use-install-prompt.ts`）——不得两条安装提示并存。
- [ ] 点安装条「安装」钮 → Chrome 原生安装对话框；**取消对话框后安装钮退场换结果反馈行**（prompt 一次性，不能再点必败按钮）。
- [ ] 安装成功 → 桌面/抽屉出现图标；从图标启动 = standalone（无浏览器 chrome）。
- [ ] standalone 内系统返回键：应用视图按返回 → 回 Home 不退出 PWA；最近任务覆盖层开着按返回 → **先关覆盖层**（应用栈位不被花掉）。

### 2.3 手势：上滑 / 长按 / 边缘返回（阈值 §35.9 速查）

- [ ] **边缘返回**：左缘 24px 带内滑入过半/快甩 → Home。**叠加观察**：Android 10+ 系统边缘返回手势（或三键返回）与 AgehaOS 手势的分界——系统手势优先区多宽、24px 带是否仍可稳定触发（记录实际体验）。
- [ ] **底缘上滑**：Dock 区上滑/快甩 → 抽屉；与系统底部手势条上滑（切最近任务）不互相误触的观察记录。
- [ ] **Dock Home 位长按**：~500ms 驻留 → 最近任务；**长按期间不弹系统上下文菜单**（contextmenu preventDefault 生效）。
- [ ] **最近任务卡片上滑**：>64px 或快甩关闭；点卡切回不重启。
- [ ] **Files 长按**：500ms 弹操作单、无系统菜单、阈值内抬起正常点击。
- [ ] 跟手无迟滞；返回手势/上滑手势在滚动中的误触率（轴向死区 10px 是否够用）。

### 2.4 软键盘与 Terminal 快捷键行

- [ ] Terminal 聚焦：键盘弹起输入行可视、快捷键行贴键盘上沿不遮挡；键盘收起恢复。
- [ ] 五键真实生效（↑↓ 召回 / Tab 补全 / Esc 清草稿 / Ctrl+C `^C`）；busy 期整行禁用。
- [ ] 输入行无自动大写/自动更正干扰（`autoCapitalize=off` 等）；回车 = send 键位提交。
- [ ] Gboard 等输入法的悬浮/单手模式遮挡评估记录。

## 3. 已知限制（验收时不要当缺陷提）

- **单全屏产品模型，无分屏多窗**：应用恒全屏单窗（AppHost 单宿主位），「多窗」= 最近任务切换（窗口常驻后台、切回不重启），不是同屏并排。分屏多窗是顺延待办（HANDOFF §4.0），当前行为即契约（ARCHITECTURE.md §3.25 M3 多 App View 模型）。
- **无假能力开关清单**：控制中心只摆真实能力开关（主题/字号/语言/减弱动效/登出）——亮度（浏览器无能力）、羽化（Settings 已有完整面板）、桌面指针特效（移动无消费位）**有意不摆**（DESIGN.md §0.5 真实性铁律、ARCHITECTURE.md §3.25 M2-3 段）；清单里没有的开关不是遗漏。
- **顺延未做**（存在即已知，不是缺陷）：manifest `mobile` 块（orientation/presentation）M0-M4 十四片均未消费；§35.4 竖屏壁纸 object-position 焦点保护未落地（竖屏当前居中裁剪）；同步无手动触发入口（M4-3 有意不设）。
- **性能阈值的口径**：`e2e/mobile-perf.spec.ts` 的 DCL<200ms/FCP<300ms/长任务≤3 是**门禁机 Chromium 冷加载**阈值（中位数×1.5 定档），不直接套真机；真机只做体感记录与回归对比。

## 4. 部署注意（真机验收前后的发布口径）

- **发布**：`npm run deploy`（清洁构建→上传前断言→releases 原子切换→六点核验→失败自动回滚）；推荐带特征标记 `npm run deploy -- --marker <特征串>`（标记必须出现在 JS bundle 内，public/ 文件内容不算）。**禁止手工 tar 部署**（PITFALLS 64/65）。
- **生产 env 口径**：deploy **不传 env**。运行时 env（LLM 上游密钥等）只配在服务器 systemd drop-in（`/etc/systemd/system/agehaos.service.d/*.conf`，600 权限；HANDOFF §2.5）——**改动必须 `systemctl daemon-reload && systemctl restart agehaos`**，并用 `/proc/<agehaos 的 MainPID>/environ` 验证生效。构建期 `VITE_*` 变量走 `.env.deploy` 这类 **Vite 不加载的名字**（`.env.production`/`.env.local` 会被 `vite build` 自动读取，`scripts/deploy.mjs:14-15` 命名铁律）。
- **服务器依赖安装**：严禁 `npm install --omit=dev`（PITFALLS 65：tsx 在 devDependencies 且是 systemd ExecStart 二进制，omit=dev 直接打断服务）。
- **发布后真机复验项**（最小冒烟， marker 核验通过后执行）：
  1. 底缘上滑开抽屉 → 全局搜索一个文件 → 点击定位到所在目录；
  2. 开 Terminal → 键盘弹起输入行可视 → 快捷键行五键各点一次；
  3. 左缘返回回 Home → Dock Home 位长按开最近任务 → 卡片上滑关卡；
  4. 通知中心跳转行点按直达；Settings→同步 状态行如实；
  5. 安装条分支正确（Android 安装钮 / iOS 指引文案）、PWA standalone 启动正常；
  6. 桌面端一屏回归（Dock 波浪跟随、Ctrl+K 面板）确认移动发布未伤桌面。
