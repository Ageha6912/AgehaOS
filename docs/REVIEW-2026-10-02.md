## P1 · 部署脚本化

### [x] 3. 部署流程手工易错（2026-10-02 已脚本化）

- **问题**：每次部署需手工执行：带 pin 构建、先删 dist、`--exclude` 必须前置、SSH 超时重试、六点核验、备份 `dist.old-prevN`、壁纸 bump `?v=N`。坑 64 / 65 / 70 与「部署卫生」一节都是手工流程事故。
- **已发生的手抄错误**：HANDOFF 中 pin 公钥两处拼写不一致——§2 生产部署段为 `...Tfal2SE=`，09-30 部署日志为 `...Tfal2Se=`。照抄错的一份会构建出验签必挂的包。
- **建议**：新增 `scripts/deploy.mjs`（`npm run deploy`）：
  1. 从 `.env.deploy`（不提交）读取 `VITE_AUTH_BACKEND` 与 `VITE_STORE_CATALOG_PUBLIC_KEY`；
  2. 删除 dist → 构建 → 断言 pin 与本轮特征标记在 bundle 内；
  3. tar 时硬编码排除 `server/data`（exclude 前置），上传到 `/opt/agehaos/releases/<timestamp>/`；
  4. 软链接原子切换 `current`，只保留最近 3 个 release（顺带解决旧 bundle 累积与 `dist.old-prev*` 清理）；
  5. 检测 `package-lock.json` 是否变化 → 是则远端执行完整 `npm install`（**禁止** `--omit=dev`，坑 65）；
  6. 检测 `src/server` 是否变化 → 是则 `systemctl restart agehaos`；
  7. 自动跑六点核验（全部 `--resolve` SNI），任一失败自动切回上一 release；
  8. SSH 统一 `ConnectTimeout=15` + 3 次重试。
- **验收**：一条命令完成部署与核验；故意填错 pin 时脚本在上传前失败；回滚命令 `npm run deploy:rollback` 可用。
- **执行**：`scripts/deploy.mjs`（npm run deploy / deploy:rollback）实现建议的全部 8 步：.env.production 读取 + pin 形状校验（手抄错在上传前拦截，实测 exit 1）、清洁构建、exclude 前置 tar 上传 releases/<时间戳>、dist 符号链接原子切换（Caddy 零改动）保留 3 份、lock 变化才 npm install（禁 --omit=dev）、server/src 变化才重启（等监听）、六点核验自动（失败自动回滚）、SSH 重试。实测：部署×3 + 回滚×1 + 坏 pin 拦截全过；部署库测试 11 例（node --test，并入 npm run test）。HANDOFF pin 手抄错已修（Tfal2Se= → Tfal2SE=）。旧 dist.old-prev×7 已清；新布局下旧 bundle 累积不复存在。**教训入册**：脚本首版曾有 `rm -rf server` 同款吃数据地雷（09-27 事故模式），评审前自查改为只替换 server/src|test。

## P2 · 性能与测试结构

### [ ] 8. 缺少性能预算与设备分级降档

- **问题**：五项动效默认全开（aurora canvas、指针光晕、Dock 扫光、主题光晕、窗口倾斜），叠加七档 backdrop-filter（最高 44px）。目前降级只看 `prefers-reduced-motion`，集显 / 低端笔记本可能明显掉帧。
- **建议**：
  - 启动时设备分级：`navigator.deviceMemory`、`hardwareConcurrency`，或前 2–3 秒实测帧率 → 自动降档（关闭 aurora / tilt，blur 减半）；用户手动设置优先。
  - E2E 加性能基线：开机后桌面空闲帧率、开窗 / 拖拽期间长任务数（Performance API / CDP 采集）。
- **验收**：低档设备默认动效配置有测试覆盖；性能基线进 E2E。

### [ ] 9. 单测过度钉扎视觉实现细节

- **问题**：大量单测断言类名与像素值（blur 12px、`z-[45]`、「className 不含 `bg-surface-raised`」、CSS↔TS 互指钉扎），每次视觉调整都要同步改测试，测试成为阻力而非保护。
- **建议**：
  - 纯视觉钉扎收敛为少量 Playwright 截图对比（`toHaveScreenshot`，固定视口 / 主题 / 关闭动效）；
  - 单测只保留行为契约（打开 / 关闭 / 焦点 / 可达性 / 几何不变量如「最大化覆盖整视口」）；
  - 保留真正防回归的少数钉扎（如 backdrop-filter 标准属性存在，HANDOFF 根因 A）。
- **验收**：一次纯视觉调整需改动的单测数量明显下降；截图基线进仓库。
