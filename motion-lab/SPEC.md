# AgehaOS 动效实验室 · 动效语言规范（SPEC）

> 适用范围：`motion-lab/` 下全部独立演示模块。本文是动效语言在实验室内的
> 唯一权威约定；视觉基调的权威定义在 `docs/DESIGN.md`，色板/阴影/玻璃的
> 数值权威在 `src/index.css`（--ag-*），共享令牌在 `shared/tokens.css`（--ml-*）。
>
> 理论底座：macOS Big Sur 及之后的系统动效语言（本质是 Apple《Designing
> Fluid Interfaces》WWDC 2018 一脉的思想——回应即时、连续可中断、带动量、
> 材质表达层级），翻译为 Web 合成层动画实现。

---

## 0. 一句话气质

**克制、流畅、有物理感。** 仪表不闪烁：每个动效都必须能回答「为什么动」——
表达空间关系（从哪来、回哪去）、反馈状态变化（发生了什么）、或承接动量
（用户的力还在）。三者皆无，就不要动。宁少动，不乱动。

---

## 1. macOS 动效语言五法则（提炼）

### 1.1 空间连续，来源锚定
东西从哪里消失，就从哪里回来。浮层必须从**触发它的元素**长出来：
菜单从菜单项、窗口从 Dock 图标/任务栏按钮——用 `transform-origin` 指向
触发源（或 JS 把 origin 算到触发点坐标）。进出场沿**同一路径**：出场
默认用惯例加速曲线 `--ml-ease-in`（消失比出现快）；需要严格路径对称时
（如同一浮层的开与关），按镜像公式换算出场曲线——进场曲线每个控制点取
`(1-x, 1-y)`。反向走不同路径会瞬间瓦解空间感。

### 1.2 弹性即质量
macOS 的「手感」来自弹簧：默认**临界阻尼**（无过冲，优雅落定），只有
**真正携带动量的交互**（甩动、拖拽释放、任务栏滑入）才允许过冲。
映射：日常进场用 `--ml-ease-standard` / `--ml-ease-spring`（无真过冲的
冲劲）；过冲只允许 `--ml-ease-spring-bounce`（约 4% 过冲，克制档）。
JS 驱动的跟随类动效（Dock、拖拽）必须从**当前呈现值**续动、可随时反向
——动画永远可以被用户半路抓住，不许锁输入。

### 1.3 距离衰减波浪
Dock 放大的本质：指针是扰动源，图标按**与指针的距离**衰减参与——
近者放大多、远者放大少且趋于 1，形成连续的波浪而非孤立的跳跃。
实现约定：高斯/余弦式衰减函数（如 `scale = 1 + (max-1) · exp(-d²/2σ²)`），
rAF 逐帧计算、1:1 跟随指针（无 CSS transition 参与跟随段），
指针离开后用一段 200ms 级的收敛回落。相邻图标间不得出现离散跳变。

### 1.4 节奏分层
- **退场比进场快**：进场 `--ml-dur-base/mid`，退场取同档或降一档 +
  `--ml-ease-in`（消失不拖泥带水）。
- **通知三段节奏**：滑入（250ms 级）→ 驻留（约 5s，静）→ 滑出（200ms 级，
  加速）。驻留期必须完全静止——仪表不闪烁（DESIGN.md §2.5：不新增循环动画）。
- **错峰（stagger）**：多个同类元素依次入场时，间隔 40~60ms、共用同一条
  曲线，制造「一层层就位」的秩序感；间隔禁止超过 100ms（会变成拖沓）。

### 1.5 材质真实
毛玻璃不是透明度动画，是**材质到达**：玻璃浮层入场时 blur/scale/opacity
三者一起到位（「materialize」），读起来像一块真实材料落进画面，而不是
一张图片淡入。规则：玻璃归 chrome（任务栏/开始菜单/通知/标题区），纸面
归应用；浅层玻璃上不再叠浅层玻璃（可读性崩塌）；blur 值永不逐帧动画，
档位间只做一次性切换（见 §4）。

## 2. 典型场景映射表

| 场景 | macOS 原型 | 变形（transform/opacity only） | 曲线 | 时长 | 关键约定 |
| --- | --- | --- | --- | --- | --- |
| 窗口开合 | 从触发源弹性缩放展开 | `scale 0.92→1` + `opacity 0→1`，origin 朝触发源 | `--ml-ease-spring` | 250ms | 关闭走镜像路径：`scale 0.96→1 + fade`，200ms `--ml-ease-in`；关闭时长恒短于打开 |
| Dock 放大波浪 | 距离衰减放大 | 每帧写 `scale`（rAF），无 transition 跟随段 | 衰减函数 + 收敛段 `--ml-ease-standard` | 跟随 0ms / 收敛 200ms | 1:1 跟随指针；`--ml-shadow-lift` 随放大出现；离开后整体收敛回 1 |
| 通知横幅 | 顶部滑入-驻留-滑出 | 滑入 `translateY(-100%)→0` + fade；滑出反向 | 进 `--ml-ease-spring-bounce`（有滑入动量）/ 出 `--ml-ease-in` | 进 250ms / 出 200ms / 驻留 5s | 多条错峰 40~60ms；驻留期完全静止；hover 驻留暂停计时 |
| 菜单淡入+位移 | 从触发点轻微上浮显现 | `opacity 0→1` + `translateY(4px)→0`（或 `scale 0.98→1`），origin 顶部 | `--ml-ease-standard` | 200ms | 位移方向与展开方向一致（下拉菜单向下浮入）；关闭 150ms，仅 fade 或反向微移 |
| 任务栏/开始菜单 | 底缘滑入、大面弹性 | `translateY(100%)→0` | 滑入 `--ml-ease-spring` / 开始菜单主体 `--ml-ease-standard` | 300ms | 与产品现状一致（DESIGN.md §9：300ms 滑入/400ms 缓冲收起，收起属缓冲计时非动画时长） |
| 开机动画 | 品牌亮相、唯一豁免档 | opacity / 轻微 scale | `--ml-ease-standard` | 允许 >300ms（如 400ms 档及以上） | 必须在模块 PARAMS 注释中说明豁免理由；进度感靠内容本身，不加循环动画 |

> 表内时长均为铁律范围内的默认值；模块微调仍须落在 150~300ms。

## 3. 实现铁律（性能红线，逐条可验收）

1. **时长**：一切过渡 150~300ms，唯一豁免是开机动画（并须注释说明）。
2. **属性**：只用 `transform` / `opacity`（transition、animation 或 rAF 皆可）。
   禁止过渡/逐帧写 `width`、`height`、`top`、`left`、`margin`、`padding`、
   `box-shadow`、`font-size` 等布局/绘制属性——它们触发布局抖动。
3. **rAF 纪律**：指针驱动的连续动效（Dock 波浪、拖拽跟随）一律
   `requestAnimationFrame` 节流——每帧最多一次写操作，事件回调里只记数据；
   能用 CSS transition 表达的非连续动效，优先 CSS（让合成器接管）。
   rAF 动画必须可中断：从元素当前呈现值续算，不回跳起点。
4. **blur 不参与逐帧动画**：`backdrop-filter` 档位只做一次性切换；
   入场「materialize」效果用预置 keyframes 一次性走完（blur+scale+opacity）。
5. **`will-change` 纪律**：只在动效即将发生前挂上，结束后移除；
   常驻挂载会耗尽合成层预算。
6. **中断性**：CSS transition 天然可中断（保留）；rAF 实现必须读当前值
   续动、允许反向，禁止在过渡期间锁输入。

## 4. 令牌与 PARAMS 的分工

- **令牌（`shared/tokens.css`，--ml-\*）= 系统级常量**：曲线、时长档、
  色板、玻璃、阴影、z 层。模块 CSS 一律 `var(--ml-*)` 引用，禁止散落魔数。
  主题切换：给 `<html>` 或舞台容器加 `class="ml-dark"`，整套语义自动翻转。
- **PARAMS = 模块级可调参数**：只属于该模块个性的量——缩放幅度、位移
  距离、衰减宽度、驻留秒数等。**集中在模块 JS 顶部的唯一 `PARAMS`
  常量对象**，带中文注释，调性能只动这里。

约定写法（示例，模块按需增删字段）：

```js
/**
 * 模块动效参数——按性能表现微调时只改这里（全部中文注释）。
 */
const PARAMS = {
  duration: 250,            // 开合时长 ms（铁律 150~300，对应 --ml-dur-mid）
  ease: 'var(--ml-ease-spring)', // CSS 侧引用令牌曲线；rAF 侧用下方贝塞尔控制点
  bezier: [0.32, 0.72, 0, 1],    // rAF 插值用的同款曲线控制点（与令牌同值）
  scaleFrom: 0.92,          // 窗口起始缩放（越小弹性感越强）
  shiftPx: 4,               // 菜单位移距离 px（浮出量）
  staggerMs: 50,            // 多元素错峰间隔 ms（40~60）
  dwellMs: 5000,            // 通知驻留时长 ms
  reducedMotion: false,     // 运行时由 matchMedia 检测覆写（见 §5），不许手填
};
```

- PARAMS 中的时长**必须**引用档位语义（对应 `--ml-dur-*` 之一），不得
  出现脱离档位的孤立数值；模块 CSS 与 JS 各自引用时以注释互指，保证同源。
- 每模块三文件：`index.html` + `style.css` + `script.js`；`style.css`
  第一行 `@import "../shared/tokens.css";`。禁止任何外部网络依赖
  （字体/CDN/图标库），双击 `index.html` 即可预览。

## 5. prefers-reduced-motion 降级（必须实现，逐模块验收）

令牌层已提供 CSS 兜底：`@media (prefers-reduced-motion: reduce)` 下所有
`--ml-dur-*` 塌缩到 0.01ms，纯 CSS 模块引用令牌即自动「动效关闭」。
JS（rAF）驱动的模块**必须在 JS 里检测**：

```js
const REDUCED = matchMedia('(prefers-reduced-motion: reduce)').matches;
```

降级形态（二选一，模块内注明选型）：

| 动效类型 | 降级形态 |
| --- | --- |
| 进出场（窗口/菜单/通知） | 仅保留 ≤150ms 的 opacity 交叉淡化，位移与缩放归零 |
| Dock 放大 | 关闭波浪，保留 hover 高亮/描边（状态可感知即可） |
| 跟随/拖拽类 | 元素 1:1 瞬时跟随（无惯性与回弹），落定无动画 |
| 开机动画 | 短促淡入直接呈现最终画面 |

附加：`prefers-reduced-transparency: reduce` 已在令牌层把玻璃退化为实色、
blur 归零，玻璃类模块无需额外处理；键盘焦点永远不能被动效吞掉
（`:focus-visible` 环照常渲染）。

## 6. 模块验收清单（提交前自查）

- [ ] 全部过渡时长在 150~300ms（豁免处有注释说明）；曲线/色板/阴影/玻璃/z 全部走 `--ml-*` 令牌
- [ ] 只动 `transform`/`opacity`；无布局属性过渡；blur 无逐帧动画
- [ ] 指针驱动部分经 rAF 节流、可中断、从当前值续动
- [ ] JS 顶部唯一 `PARAMS` 对象、字段全中文注释、时长字段对应令牌档位
- [ ] `prefers-reduced-motion: reduce` 降级可运行（CSS 模块靠令牌自动降级；JS 模块有 matchMedia 分支）
