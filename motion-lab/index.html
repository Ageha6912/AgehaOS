MOTION LAB

AgehaOS 动效实验室

参照 macOS Big Sur 及之后版本的动效设计语言，为启动流程与界面交互准备的高质量视觉动效演示。 全部模块框架无关：双击各模块 index.html 即可在浏览器直接预览。 性能铁律：过渡 150~300ms（开机动画豁免）· 只动 transform/opacity · 全量提供 prefers-reduced-motion 降级。动效语言规范见 SPEC.md， 设计与集成文档见 README.md。

核心动效 开机 / 窗口 / Dock / 菜单与通知——桌面体验的主干动效

boot 开机启动动画

纯黑全屏启动层 + 品牌 Logo + rAF 四段变速（快-慢-慢-冲刺）细长进度条，3.8s 完成后启动层淡出放大露出毛玻璃登录占位卡；暴露 window.AgehaBoot 对接接口与 data-boot 测试钩子。

在新标签打开 demo →

window 窗口生命周期

macOS Big Sur 式窗口动效：从 Dock 图标弹性长出（scale 0.9→1 + fade）、沿原路收拢关闭（恒短于打开）、genie 式最小化飞行与 anim.reverse() 严格镜像还原，半途可抓回。

在新标签打开 demo →

dock Dock 放大波浪

rAF 驱动的高斯距离衰减放大波浪（scale + translateY 合成层动画、帧内零布局读取）+ 玻璃底座 + 名称 tooltip + 发光激活点，含触屏 / 键盘 / reduced-motion 三路降级。

在新标签打开 demo →

menu-toast 菜单与通知

右键上下文菜单与顶部下拉共用「淡入 + 上浮 4px」同款动效；系统通知右上角滑入 → 驻留（hover 暂停）→ 滑出，多条向下堆叠、腾位上移走 transform；「定位层 + 动效层」双层架构可中断。

在新标签打开 demo →

基础增强 低成本日常质感——建议默认全开的保守档

enhance-basic 基础增强档（5 项）

毛玻璃拟态面板、图标按压微动效、进桌面错峰入场、鼠标跟随光晕、点击涟漪——五个独立 .css/.js 效果 + 一个可开关的组合演示页，全部遵守 150~300ms 与 transform/opacity 铁律。

在新标签打开组合 demo →

进阶炫技 氛围与转场——按硬件与场景选开的高成本档

enhance-advanced 进阶炫技档（5 项）

壁纸三层视差景深、Canvas 流光氛围、窗口切换 crossfade + 3D tilt、Dock 斜向扫光、主题光晕呼吸；组合演示页默认仅开「视差 + 光晕」两项，其余按需开关。
